## Acerca de

Este repositorio contiene el código de la página pública de **Alkes**: la que presenta el producto, sus planes y su información legal. Está hecha a mano, sin librerías de interfaz, con atención a velocidad, accesibilidad y posicionamiento en buscadores.

## Tecnología

| | |
|---|---|
| Interfaz | HTML, CSS y JavaScript propios |
| Tipografías | Autoalojadas |
| Temas | Claro y oscuro |
| Diseño | Adaptable a celular, tableta y escritorio |

## Cómo se ejecuta

Es un sitio estático: sirve la carpeta del repositorio con cualquier servidor web. No hay paso de compilación.
